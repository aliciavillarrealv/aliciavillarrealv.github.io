# Alicia Villarreal Villacrés · UX/UI Portfolio

Static site, ready for GitHub Pages.

## Publish
1. Create a public repository, for example `portfolio`.
2. Upload everything in this folder (index.html, img/, cv/).
3. Settings → Pages → Source: "Deploy from a branch" → main / root → Save.
4. In a minute it is live at https://YOUR-USER.github.io/portfolio/

## Contact form
The form uses FormSubmit (free, no account). The first message triggers a confirmation email to andrea.villarreal.v@gmail.com: open it and click "Activate". After that, every message arrives in that inbox.

## Custom domain (optional)
Buy a domain (e.g. aliciavillarreal.com), add it in Settings → Pages → Custom domain, and point the DNS as GitHub explains.
